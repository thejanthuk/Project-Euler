# Project Euler (Problems 1-100)

From [Project Euler](https://projecteuler.net/about):

> Project Euler is a series of challenging mathematical/computer programming problems
> that will require more than just mathematical insights to solve. Although mathematics
> will help you arrive at elegant and efficient methods, the use of a computer and
> programming skills will be required to solve most problems.

This repository contains my solutions to problems 1–100, each with a short note on the method and its complexity.

## Disclaimer
Project Euler allows publishing solutions only for problems 1–100.
If you haven't solved a problem yet, try it yourself first.
